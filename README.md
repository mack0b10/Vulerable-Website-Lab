🔐 Vulnerable Website Security Lab

Node.js | Express.js | Kali Linux | Nmap | Burp Suite | Security Monitoring

A hands-on cybersecurity project focused on web application security testing, network reconnaissance, authentication monitoring, and vulnerability analysis.

This project involves building a web application from scratch, configuring a testing environment across two computers, and using cybersecurity tools to understand how web applications communicate, how security weaknesses can occur, and how those weaknesses can be identified and remediated.
